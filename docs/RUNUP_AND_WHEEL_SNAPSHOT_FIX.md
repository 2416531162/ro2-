# 助跑上线连续性与轮速并发修复（2026-10-05）

用户最终要求：助跑目标0.5m/s，正常助跑不希望低于0.3m/s；不是“头0.5米低速”。助跑空间延长至1.5m，上线时应与中段一样平稳。静止起步的加速度约束、必要刹停、曲线限速和比0.3m/s更低的明确巡航设定不强行抬高。

## 记录依据

24e5448d9bbc23bf 上的8趟路线：6趟行驶完成，e602ab91因CAN缓冲错误进入FAULT，bcf8fc86收到操作员暂停/结束指令。正式喷线区间估算峰值约1.0～2.1cm；较大误差主要在上线前。多趟进入前进段时航向还差约2～5°，前1m喷头估算横偏达3～5.2cm。右偏配置先后为0.4675/0.4775/0.4475m，不能把这些趟都看成同一标定对照。

另有直接软件崩溃：底盘服务在发布停稳状态时调用HallSpeed.at，和I/O线程更新deque并发，抛出 RuntimeError: deque mutated during iteration。服务随后自动重启。该错误已在原版以两个线程确定性复现。

## 修改

- HallSpeed写入/重置与读快照同步；复制后释放锁，计算不占用写锁。停稳读取避免复用可被清空的队列尾索引。保持原测速及停稳数值规则。
- CAN异常补充失败报文ID、报文内容、重试/超时计数及堆栈，区分速度、心跳、查询或接收失败。原故障停车规则保留；这只是提高诊断完整性，未宣称消除了CAN拥堵。
- 单条路线的初始接入、续画接入及场地每条已标记刷线的助跑，统一按喷头离线头的实际距离留足1.5m。原侧置喷头前伸0.23m时，旧1.2m后轴参数只产生0.97m实际助跑。新计算与喷头前伸量无关，A/B和正式喷线目标不移动。
- 已标记的前进助跑目标0.5m/s；按巡航速度、加速度、执行延迟和0.2m余量预留加速距离，在线头前接到巡航。长直线内环在助跑阶段更早开始平滑接管，不在跨线头时重新创建控制器或突然改速度。助跑结束后保留直线定速策略。
- 普通多点路线内部既有折返/圆弧掉头几何不扩展，避免改变未独立标记的喷线区间；场地规划的run_in标记同步到1.5m。车端生成的执行/预览路径继续上报平板。平板本机独立几何仿真的旧助跑参数本次未调整。

## 验证

控制、并发、协议与喷线：212测试、113子测试通过。
接入、规划、场地、直线定速与上线连续性：121测试、36子测试通过。1项既有field_planner测试在未修改501a763基线上同样失败（线尾滑行喷线期间current_role断言），已单列证据，不计通过。
几何测试覆盖不同喷头前伸/侧置和方向，确认助跑恰为1.5m且原A/B不变。运动学测试确认助跑稳定段0.3～0.5m/s、上线前达到0.8m/s、跨线头控制器实例连续及指令无突跳。

以8趟记录的初始位置/航向估计作为模型初态，配3种底盘动态，共24组配对，均完成。候选在跨线头时真实模型车速均0.8m/s，速度指令变化为0。线头前1m横偏P95工况中位1.11→1.21cm，最坏峰值2.37→2.26cm；中段P95中位1.46→1.58cm。候选所有工况的线头P95均未超过各自中段P95+0.5cm（基线4例超过）。因此衔接达到本轮模型验收，但绝对误差没有全面改善。

这些是保留相同噪声/模型的闭环计算，初态来自定位估算，不是原实车轨迹的精确重现；不能承诺所有地面情况下线头都与中段完全相同。仍需同线实车复跑。
