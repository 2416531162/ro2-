# 足球场圆弧走法：连续行驶与平顺提速

2026-10-07 用户要求：导入足球场后选择圆弧走法，全场正常作业连续向前；一笔结束只停喷，不为换段停车。起步、出弯提速柔和。

## 实现

- `field_planner.transit` 的 `turn=arc` 只选向前 Dubins 连接，不再按空间评分回退到倒车、原地转向。外场包络仍如实预览，启动沿用既有外场确认。
- 每个逻辑作业段仍有自己的喷涂窗口。内部 `motions[].continuous_after` 标记下一段不停顿交接，最后一段为 false。该字段由规划服务传给任务执行层，不改变 App 请求、预览或遥测格式，无须同步修改 App 常数。
- `SectionTracker` 校验前后段位置、切线、前进方向及检查暂停标记；不满足则拒绝连续执行。前视跨过逻辑分界，实际车位到达分界后才切换喷线窗口。速度、加速度、曲率反馈、已发指令与前馈历史连续传递，转场不重新执行起步慢行。
- 场地圆/弧的正式喷涂终点保持图纸原位置，终点外沿同一圆继续 0.5 m 不喷，供最终缓停或连续转场。绕圈切入改变助跑长度时，喷涂终点同步平移。
- Gen5 含圆弧或连续衔接的前进段，提速上限为 0.25 m/s²，加速度变化上限为 0.5 m/s³。仅限制正向提速，刹车、暂停、不可用定位与硬停车约束优先。倒车和普通独立直线保持原配置。
- 连续标记保存到任务快照；裁剪剩余路线、重新接入和恢复后仍保留。`field_context` 保存所选转弯方式与半径，续画及局部补画使用同一方式。缺少新字段的旧任务按原语义运行。
