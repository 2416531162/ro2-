# 深度相机补充雷达通路观测

跟随节点订阅 `/camera/depth_raw/image` 和对应的 `/camera/depth_raw/camera_info`。
使用原始有效深度确认雷达未覆盖的路径位置，不使用人体检测框或人体距离证明地面空闲。
当前实现与现有二维雷达规划器一致，仅补充**已标定雷达扫描平面上下 3 cm** 的观测，
不是全车高度的体积避障，也不检测坑洼、台阶落差或可靠识别透明玻璃。
相机也可能看穿玻璃，有效深度不等于能识别所有透明表面；玻璃环境仍需要实地验证。

## 启用条件

配置文件为 `/etc/rk3588/depth_path.json`，可由 `RK3588_DEPTH_PATH_CONFIG` 指定其他路径。
启动脚本从 `/etc/rk3588/runtime.env`（或 `ROBOT_RUNTIME_ENV`）读此键；进程环境覆盖文件值，建议用绝对路径。
参考 `radar_system/config/depth_path.example.json`，模板中的 null 故意不能通过校验。
没有文件、字段未填写、参数不合理或 `profile_hash` 不匹配时，保持雷达原有停车判断，
网页明确显示“等待相机与雷达高度标定”或“深度标定不匹配”，不默认为同高。

- `profile_hash`：当前 `/follower/status` 的 `profile_hash`；底盘配置变化后必须重核标定。
- `optical_frame`：深度图实际使用的光学坐标系，须与对应 CameraInfo 一致。
- `x_m` / `y_m`：**相机光心**相对后轴中心的位置，向前/向左为正，单位米。
- `yaw_rad` / `pitch_rad`：光轴偏航和向下俯角，单位弧度。
- `lidar_minus_camera_height_m`：雷达扫描平面高度减去相机光心高度；雷达高于光心为正。
- `min_depth_m` / `max_depth_m`：现场验证的有效深度范围，默认保守使用 0.35–2.5 m。

不要把相机外壳或 `camera_link` 的位置直接当成光心。
2026-09-18 板端只读检查中，深度图和内参均为 `camera_rgb_optical_frame`、640×480，
驱动 TF 的 `camera_link → camera_rgb_frame` 存在 y=-0.045 m 的平移。
现有底盘配置没有相机/雷达高度差，也没有完整的 base→camera TF；不能假定高度差为零。
使用相机安装标定和 TF 换算光心位置后，填写上述外参并重启被动跟随服务。

## 决策约束

1. 深度图、内参必须同坐标系、同分辨率，时间差不超过 80 ms。
   当前使用原始深度图及 CameraInfo 的 `K`，仅接受无畸变、无裁剪、未缩放的针孔图像；
   `P` 属于矫正后的投影，不用它来否决原始图像的有效 `K`。其他输入明确拒绝。
2. 图像年龄不超过 200 ms，使用采集时刻里程计补偿车身移动和转向。
   没有采集位姿、定位重置、过期、未来帧、错误图像或标定变化均不能继续使用旧证据。
3. 待查位置必须在视野与有效测距范围内；3×3 像素邻域及扫描平面上下三个采样高度
   都有有效深度，且最小深度比待查位置远至少 5 cm，才确认该位置空闲。
   深度零值、NaN、inf、画面外、近距离盲区都不算空地。
4. 仅补充雷达未知空间，不覆盖雷达实测障碍；深度看到的近障碍优先于历史空闲。
   雷达断流/不可用时，整车仍按原规则停车，不切换为纯相机驾驶。
5. 相机确认只支持前向路径，倒车保持雷达与历史走廊规则。
   实际限速后转角的整条扫掠路径仍复核；依赖相机确认时速度上限 0.12 m/s。
   控制计算结束再检查一次深度时效，过期则输出零速。
6. 相机证据不写入雷达历史缓存，不允许反复沿用旧帧维持空地。

## 诊断

`/follower/status.depth_path` 包含 `reason`、`calibration_error`、`intrinsics_error`、
`calibrated`、`received`、`accepted`、
`age_ms`、`valid_ratio`、`used`。`ready` 只说明深度帧可供查询，不代表整条路径已确认。
只有 `used=true` 才表示实际路径计算用到了相机补充；最终仍可能因另一处未知区域停车。
网页“相机通路确认”一栏展示状态。

当前现场卡住的点为车体系 (0.715, -0.08) m，距现有相机安装位置向前约 0.175 m。
这个位置可能不在相机的有效近距/垂直视野中；不能承诺加深度相机后该缺口自动消失。
必须用实测高度差检查覆盖，必要时调整传感器安装或补充近距感知。

## 验证

`python3 -m pytest tests/test_depth_path.py -q`

覆盖深度补充放行、空洞、真实近障碍、雷达障碍优先、过期/未来帧、内参不匹配、
姿态变换、扫描高度、近距盲区、反向不放行、限速、断流停车和计算中深度过期。
这些是合成深度与 ROS 替身测试，不是玻璃检出率验证或实车运动验收。
