# 手动水泵：HC-08 转发至单片机右下输出

2026-10-04：支持 `connection_independent` 的新版由板子给输出进程续租；平板断开或后台不再关泵，已有输出保持，恢复连接后可关闭或调整。急停、故障、推行、底盘状态过期与输出进程中断仍关闭，详见 [平板连接协议](APP_PROTOCOL.md)。下文旧版的平板续租描述仅适用于未上报该能力的服务。

平板沿用水泵开关和压力 1–100：RK3588 通过板载蓝牙连接指定 HC-08，
HC-08 将原始串口指令交给德国整平机控制器。压力就是右下通道最大输出限幅百分比。
不增加 MCU 协议、不修改 MCU 固件；PWM 频率、极性、引脚映射和软启动仍由 MCU 参数决定。
默认映射的右下为 TIM4 CH4 / PB9，修改过映射的控制器仍按其右下逻辑方向输出。

## HC-08 配置

车端 `/etc/rk3588/runtime.env`：

```ini
RK3588_PUMP_ENABLED=1
RK3588_PUMP_BACKEND=hc08
RK3588_HC08_ADDRESS=F8:2E:0C:E3:A0:A8
RK3588_HC08_ADAPTER=hci0
```

`PumpControl.from_env()` 默认选 hc08；显式选择 gpio 可使用下文的原 GPIO0_C6 后端。
蓝牙后端使用系统 BlueZ、python3-dbus 和 python3-gi，不占用平板 RTK 的 RFCOMM 通道。
按设备地址和 FFE1 特征 UUID 查找串口，不固定服务或特征句柄路径。
HC-08 必须双向接通 MCU UART；蓝牙已连接但没有 MCU 回读时显示不可用。
服务启动和重连只建立蓝牙、停止旧动作、切手动、查询状态，不会自动开启水泵。
蓝牙建连使用异步等待；不会用 2 秒同步超时打断仍在等待模块广播的连接。
模块未连接时明确提示检查供电与其他设备占用；串口通知订阅允许等待 3 秒。

## MCU 既有指令

| 操作 | 原始字节 | 说明 |
| --- | --- | --- |
| 设置右下限幅 | `BB 15 RU pressure 55` | RU 保留 AA14 回读的右上限幅；pressure=1..100 |
| 右下开启或续租 | `BB C1 04 00 55` | 开启期间每 200 ms 发送；MCU 租约 500 ms |
| 停止手动输出 | `BB C1 00 00 55` | 关闭、退出、失联与故障时发送 |
| 切手动模式 | `BB C2 00 00 55` | 仅初始化或重连，防止停止手动后回到自动输出 |
| 查询参数 | `BB FF CC FF 55` | 读取 MCU 参数和状态 |
| 请求方向诊断 | `BB D0 01 00 55` | AA D0 回读逻辑通道输出位 |

例如右上限幅为 71、压力 37：发送 `BB 15 47 25 55`，收到新的 AA14 右下=37 回读后，
才发送右下开启指令。压力变化时只发送一次 BB15；续租只发 C1，避免重复触发参数存储。
BB15 沿用 MCU 已有的参数保存机制。关闭不将限幅写成 0，而是发送停止动作指令。

## 蓝牙输出确认与关闭

Gen5 前进直线的喷漆资格按当前实际喷头到 `paint_to_m` 处图纸线尾的沿线距离判断，独立于路径控制器的预测 DONE。
直线停车线尾按 `LINE_END_RUN_OUT.md`：越过线尾后停喷并缓停，规划的直线开出段为 0.40 m；开出、原地转向、倒车、转场和助跑都不喷。
同一圆弧掉头路线可有多个 `paint_spans`；截止锁存按“跟踪器、段号、区间号”分别保存。
旧记录没有 `paint_to` 时仍以段尾为喷线终点；旧段的 DONE 滑行喷涂资格保持原保护和采样余量。
此逻辑只管理资格，不会自动开启已关闭的硬件水泵。

可选环境项 `RK3588_SPRAY_CLOSE_DELAY_S` 是实测“关泵命令到断料”的秒数，默认 `0`，允许 `0..0.5`。
旧记录按实际喷头沿线速度提前关泵，保留原采样余量；非法值禁止喷线。新直线区间按用户要求越线 5 mm 确认后才关闭，不应用提前关泵补偿。
不要填入底盘 `delay_s` / `lead_s`，也不要通过此项补偿停车位置。实际延迟未知时，几何截止不能保证物理漆边绝不越点。
3 cm 偏线、静止、定位质量、trace 新鲜度、HC-08 的 500 ms MCU 租约等保护保持有效。
场地直线采用同一段尾逻辑；圆作业及场地末尾为圆弧的分段仍走原来的 DONE / 补喷资格。

初始必须收到手动状态、零 PWM/零方向位、合法通道限幅及 PWM 频率回读，才报告可用。
开启确认需要新的 AA D0 仅右下位（0x08）和 AA04 左侧为零、右侧非零。
参数未确认、方向不符、切自动、保护生效或反馈过期均停止并报告错误。
压力调节的开启确认使用本次会话 token，不能沿用之前的确认。

平板每 500 ms 发 pump/keepalive，车端和独立输出进程使用 2 秒会话租约。
后台、平板断连、车辆状态过期、急停、故障与推行模式沿用原有停泵联锁。
HC-08 断连后不续发右下；单片机自身 500 ms 手动租约负责停止。
蓝牙恢复后保持关闭，要求用户重新点击开启；迟到的 keepalive 不能恢复输出。
父进程退出、标准输入关闭和 SIGTERM 均发送停止指令，再释放本进程的通知订阅。
不主动断开 HC-08 共享连接，不操作其他蓝牙设备。

`tel.pump` 沿用现有字段，平板界面和上行协议不变。蓝牙后端 pin=MCU_RIGHT_DOWN，
active_level/off_level=controller，frequency_hz 取 MCU 回读，描述的是控制器逻辑输出。

本次代码基于当前板端提交 `8d97ebd`，相关测试只用假 BLE/MCU；未部署、未发送硬件输出指令。

## 原 GPIO 后端（显式选择 gpio）

App 主页显示水泵开关，压力填写整数 1–100，直接对应高电平占空比，不是压力传感器读数。
默认 50 Hz：50 表示每个 20 ms 周期输出 3.3V 高电平约 10 ms，100 表示持续高电平。
关闭、启动服务、PWM 非高电平阶段、超时、急停、断连及正常停止服务均输出低电平。
这次改动替代 GPIO1_B1 的低电平开漏控制，不改变路线自动喷涂能力声明。

## 接线与配置

- P0_C6 是 JP5 第 10 脚，GPIO bank label `gpio0`、line offset `22`，3.3V 电源域。
- 泵控制线移到 P0_C6，与驱动共地，拔掉这一排将 P0_C6 与 P1_B5 短接的蓝色跳线帽。
  不直接接水泵电源，也不能接 5V/24V 输入电压。
- 请求 GPIO 前按 chip label 核对 gpio0，拒绝旧 gpio1 配置；占用时报错，不抢占。
- `RK3588_PUMP_ENABLED=1` 启用，默认配置样例为 0。`RK3588_PUMP_PWM_HZ=50`。
  `RK3588_PUMP_GPIOCHIP` 可选；设置时必须指向 gpio0，否则拒绝操作。
- 使用 Linux GPIO v2 ABI、推挽输出、禁用内部上下拉。请求引脚时原子设为低电平。
  独立进程产生软件 PWM，频率与短脉冲仍受 Linux 调度影响。

## 协议与关闭

上行 pump/set：enabled 布尔值、pressure 为 1–100 整数、run 为 1–32 位字母数字。
前台每 500 ms 发 pump/keepalive，仅续租已开启会话；2 s 超时关闭，不自动重启。
后台、断连、车辆状态过期、急停、故障与推行模式均关闭。急停锁存经底盘复位成功解除。
关闭消息不受启用限制，任意平板均可关闭。下行 tel.pump 的 enabled 由输出进程执行确认。
新增 pin=GPIO0_C6、active_level=high、off_level=low 描述实际输出配置。
正常退出前设低；强制杀掉输出进程或系统失效时软件不能保证恢复低电平。
