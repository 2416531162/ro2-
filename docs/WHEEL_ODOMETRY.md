# Gen5 详细轮程话题

`/wheel/odometry`：`std_msgs/msg/String` 中的 JSON。仅车内使用，不要求平板转发。
`oid_driver` 每个 I/O 周期发送，包括无有效更新时的心跳；`job_recorder` 原样保存。
主机接收时钟与 `/gnss/raw` 的单调时钟同源；没有硬件采样时间。
CAN 在读到回复时标记，RS485 在每台状态查询完成时标记，不沿用阻塞查询之前的周期时刻。
总线缓存与驱动器内部测量延迟仍未标定，接收时间余量不能保证覆盖任意积压。

| 字段 | 含义 |
|---|---|
| `version` / `time_basis` | `1` / `host_receive` |
| `epoch` / `seq` | 驱动重建底盘时更新 epoch；只在有效测量时递增 seq |
| `t_rx` | 本次 I/O 周期时刻，秒；不能替代测量时刻 |
| `quality` / `reason` / `resets` | encoder、speed、pending、invalid / 原因 / 累计计数器重建次数 |
| `t` | 霍尔有效时为两轮位置的共同接收时刻，秒；位置不可用时才按回读速度对齐 |
| `speed` / `yaw_rate` | 霍尔累计位置的因果速度 / 差速角速度；霍尔初始化、缺失或过期时使用回读降级值，前进和左转为正 |
| `wheel_speed` | 保留对齐后的驱动器回读轮速 m/s，已换算为车体方向；不用于替代有效霍尔速度 |
| `speed_source` / `hall_wheel_speed` | hall 或 readback_fallback / 霍尔左右轮速，降级时为 null |
| `hall_still` / `hall_motion_age_s` | 两轮均静止为 true，有轮最近跨格为 false，证据缺失为 null / 各轮距跨格的时间 |
| `diagnostics` | 一秒区间霍尔轮程与回读速度积分长期不一致时的诊断代码 |
| `feedback_delay_s` | 已证实的固定反馈延迟补偿；本次未证实，默认 0 |
| `sigma_yaw_rate_rps` / `sigma_turn_rad` | 即时差速角速度 / 区间差速转角的量化误差余量 |
| `speed_t` / `position_t` | 两轮各自最新速度 / 累计角度回复时刻；缺失位置为 null |
| `time_uncertainty_s` / `sigma_speed_mps` | 主机接收时间余量 / 速度噪声余量 |
| `start` / `distance` / `turn` | encoder 独有：start→t 区间的有符号中心轮程 m / 差速转角 rad |
| `left_distance` / `right_distance` / `sigma_distance_m` | encoder 独有：两轮有符号区间轮程和轮程误差余量，m |

pending / invalid 心跳没有运动字段，不刷新融合输入。收到有效版本之后，不再让旧 `/odom` 把陈旧读数重新变成新测量。
启动 0.25 s 内等待详细通道，完全没有该通道的旧驱动使用旧里程计兼容；本次接入不删除 `/odom`。
计数器跳变重新建立区间起点；短缺或过期累计角度时使用对齐回读速度，sigma 至少 0.15 m/s 并标记降级。
霍尔仍新鲜而回读转速过期时允许继续用霍尔；两种反馈都缺失才停止输出有效测量。
高速按完整 60 ms 窗口的对齐轮程求速度，两个端点只使用本周期已收到的回复，避免把窗口裁成随异步接收节拍变化的短区间。
位置有效时不让较慢的 5001 回复阻塞霍尔轮程；原始回读保留自己的 `speed_t`，不会将其视作同一时刻的新测量。
低速合并最近两段完整跨格周期求速度，避免接收节拍交替长短造成正偏；超过周期没跨格时逐步下降，
静止门限为 max(0.3, min(1.0, 2.5 × 最近周期)) 秒。小于半格的累计抖动不刷新跨格时刻。
持续1.5秒以上、范围不超过1.5格、完整往返至少1秒的一格慢往返可作为有界静止证据；
这不强制速度归零，仍须卫星地速和车身角速独立确认。单向蠕行不满足。
任务层的 Gen5 停稳资格要求新鲜霍尔静止与多普勒地速 <= 0.02 m/s 同时成立，证据过期不能判停。
本批 BESTVEL 约5Hz，地速静止许可使用350ms新鲜窗，包含约200ms测量周期及接收延迟；不改变轮速/IMU的新鲜保护。
瞬时区间轮程的量化 sigma 与区间终点速度 sigma 分开，避免把一格 / 短周期的噪声当作即时速度噪声永久放大冲突门限。
运动矛盾按 0.3 秒差速积分核对，卫星速度矛盾需持续 0.2 秒；真实持续矛盾的回归测试仍必须通过。
区间在融合历史中替换速度预测，不当成独立位置观测。

普通 `/odom` 的位置也直接累加这些校验后的霍尔区间，速度及手动页面已有速度字段与详细轮程保持同源；
不会把低速估算的速度再积分成距离。计数器跳变或区间过期时不制造距离跳变。
`/oid/trace.wheels_mps` 和底盘诊断遥测的 `wheels_mps` 继续保留原始回读轮速，`velocity` 和 `/odom.twist` 使用霍尔速度或明确降级值。
ROS 速度协方差同步采用详细轮程的不确定度；车内诊断遥测 `speed_source` 标明来源，App 不新增协议字段。

配置、标定、误差预算及局限见 [GNSS_FUSION.md](GNSS_FUSION.md)。
