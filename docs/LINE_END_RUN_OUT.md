# Gen5 越过线尾关泵、缓停

2026-10-05，基于 501a763。用户最终确认：线终点前不降速，越过终点自动关泵，再缓和停下；保留 1.0 m/s，并允许该速度的越线停距超过 0.5 m。用户随后要求停止仿真，优先部署。

## 最终控制逻辑

`LINE_RUN_OUT_M=0.40` 保留直线开出几何。前进、喷线、差速且有直线开出段的控制器，在实际喷头仍未越过 `paint_to_m` 时不应用停车限速；Smith 前视、停车点预估均不能提前触发刹车。

实际喷头越过图纸线尾后，锁存 `_run_out_started`，非零速度指令按 `run_out_decel_max_mps2=1.0` m/s² 逐拍下降，直到低速。定位回摆不会重新加速。到点且实际车速低于 `1.5 * min_mps` 后才发零速，避免高速发零绕过 OID 斜坡。

新直线区间停喷按实际喷头越线 5 mm 确认，取消提前采样余量和提前关泵延迟补偿。停喷仍锁存，保护仍可随时关闭水泵。同一圆弧掉头段的各喷线区间有独立截止锁存键，区间选择保留越线确认的窗口。旧记录无 paint_to 时保留原截止兼容语义。

1.0 m/s 在 1.0 m/s² 下仅理想制动距离就为 0.5 m，执行延迟还会增加距离；用户明确接受该速度越线停距超过 0.5 m。不能用线尾前预减速来满足停距。0.5/0.8 m/s 仍以越线后 0.5 m 内缓停为目标，本版不宣称已验证实车停距。

## 几何与范围

侧置、中置前伸、后轴喷头的原地转路线急弯及最终直线线尾接不喷的开出段，后续转场/助跑从其终点接。场地每条直线同样接开出段；转场合段时 paint_from/paint_to 同时平移。App PivotRoute 同步几何。

圆弧掉头拐角进弯仍降到约 0.45 m/s，整个掉头圈不喷；取消进弯降速需要改变 ARC_RUN_OUT_M 和几何，不在本次范围。场地圆弧、圆以及短缓弯仍在曳物曲线上收尾时保持原收尾。

Section 增加 paint_to_m（None 兼容旧段尾）和 paint_spans。规划直接保存喷线角色，label_sections 不覆盖。encode/decode、场地 motions、preview、截断续画和补画都保留区间信息。
