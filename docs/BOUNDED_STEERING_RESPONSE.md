# 有界转向响应自适应

普通作业直接启动，不新增试跑、绕圈、地面选择或等待学习步骤。只使用正常控制中已有的转向输出和 IMU 角速度，不主动注入摆动。尚未通过草地实测或全场景 15 mm 最大误差验收。

## 使用范围

`PathConfig.grass_response_adaptation=True` 默认开启；同时须启用低速草地控制、差速车、巡航不超过 0.5 m/s、前进喷线直线。倒车、转场、圆弧、较高速度和其他共享航向控制调用保持原有策略。设置为 `False` 可直接恢复固定响应候选，用于对照。

只有直线内环完全接管、车辆确实移动、位置观测通过既有质量门、积分未冻结、起步收稳后才能积累学习证据。IMU 过期、重复帧、数据中断、饱和指令及明显快速旋转均不能增加学习证据。

## 学习和限制

- 记录跟踪器限幅与混合后的最终指令；`record=False` 的中间输出不用于学习。独立保留两秒有界指令历史，不受原预测队列裁剪影响。
- 使用纯 Python 的延迟/一阶响应候选模型，拟合响应倍率与小量常值偏置。前后半段互相验证；要求充分的指令变化、两半增益一致、预测残差合格，且相近模型的倍率不能相互矛盾。
- 两个互不重叠的 12 秒窗口都确认后，才调整补偿。少量纠偏不足以辨识响应时保持默认，任务不会等它学会才开始。
- 指令补偿系数硬限制为 **0.85～1.15**，正常学习每秒最多变化 **0.01**。预测中的待执行转角也按当前有效倍率换算，最终角速度上限不变，饱和时不能继续累积积分。
- 已确认模型的预测误差持续增大时，立即撤销该模型资格，平滑回退至 1.0，最大回退速度为每秒 **0.03**。之后须重新取得两个窗口的证据；不会跳到另一个倍率。没有新确认超过 36 秒也逐渐回到默认。
- 控制器重置时清除学习状态。不保存“某块场地”的永久参数，避免下一次作业带入旧补偿。

此次只自动调整响应倍率。延迟和惯性候选用于检查数据是否解释得通，**不在线改 PID 参数、预测时域或作业速度**。闭环中指令与扰动有关联，拟合得好不等于获得了真实轮胎滑移率；这是有限修正与置信门控，不是全地形精度保证。

## 诊断

`straight_hold` 新增 `adaptive_response` 和 `response_*` 字段，包括当前/目标倍率、学习门状态、样本数、已确认/被拒绝窗口、模型拟合参数、响应突变次数与回退状态。`response_fit_score` 是窗口预测评分，不是统计意义上的达标概率。

## 验证

```sh
python3 -m pytest -q tests/test_turn_response.py tests/test_grass_lateral.py tests/test_grass_closed_loop.py tests/test_paint_precision.py
uv run --with numpy python tools/grass_precision/validate_adaptive.py
uv run --with mcap --with mcap-ros2-support python tools/grass_precision/replay_adaptive.py --index /path/to/local-backup/analysis/index.json
```

固定与自适应使用同一组输入、扰动和完整计分区间。原有 156 组加上 18 组途中响应变化场景都保留，精度仍看全程最大绝对喷头横偏。新增仿真用整数计步确定沿程采样位置，修复 100 m 区间浮点累加可能漏掉线头一个样本的问题；两个对照使用相同采样，未删除任何超标点。

结果见 [自适应验证摘要](validation/grass-adaptive-20261012/summary.json)。原始 MCAP 留在本地备份。历史回放只检查当时数据能否支持学习，不能证明新算法在昨天的草地已经达到 1.5 cm。
