# 长期一致性与地速质量检查（2026-10-03）

本轮基于上一轮三路接管版本，继续修改 `gnss_fusion.py`。未部署、未提交，原来的车辆驱动看门狗和停车上限保持不变。

## 具体修改

1. 固定解位移检查同时保留 3 秒短窗和 20 秒长窗。长窗使用参考点当时的航向不确定度，沿用至少 0.005 rad 和 2σ 的余量，不因后续可疑测量更新门限。未初始化的状态不能成为参考点。
2. 长窗的轮程/IMU 位移偏差须由 Doppler 天线位移佐证，避免正常航向误差积累被直接判成 GNSS 错误。速度积分沿测量时刻推进，断流后换 epoch；不完整窗口不能提供佐证。
3. 恢复仍须回到冻结的轮程参考附近并持续符合误差范围，但 Doppler 只检查恢复观察期内的运动一致性，不要求几十秒累计的地速噪声归零。短窗与长窗故障分别保留触发来源。
4. Doppler 接管增加车体系横向残差、与可信轮速的差异、相邻速度矢量的变化检查。异常帧不刷新可信时间；持续拒绝也不扩大跳变门限。恢复需连续合格 0.2 秒。数值明显错误的地速不再被用于反过来判定轮子打滑或学习标定。
5. 上一轮的 2 秒接管、5 秒时限、误差预算及限速逻辑没有进一步放宽。本轮没有用新的 Q 参数去迎合仿真结果，也没有完成实测噪声标定。

采用的是故障隔离、分通道质量管理和恢复观察的工程思路，没有复制第三方源码，也没有声称已换成完整 ESKF/FGO。

303 项相关测试及 315 个子测试通过。上一轮确认在原始版本上也失败的差速负向用例没有作为本轮成功项。

## 仍然存在的边界

- 0.2 cm/s 的更慢漂移目前仍能通过检查。它与航向偏差、轮程比例误差、缓慢打滑可能不可区分；没有独立观测时不能仅靠软件保证识别。
- `dr_x/dr_y` 没有被 GNSS 位置直接更新，但仍依赖融合航向和轮程标定；Doppler 也来自同一接收机。这里的佐证不是物理上完全独立的第二套定位系统。
- Doppler 积分噪声用配置的 `velocity_noise_mps` 与 `doppler_correlation_s` 建模，默认相关时间 0.05 秒。额外测试覆盖了 1 秒相关噪声的若干样本，不证明任意相关性都能覆盖；实际部署前仍需要接收机日志和独立地面真值标定。
- 20 秒内转角太大、有效位移不足、推算输入不完整时，长期证据不足。不能把这些场景标成已验证的假固定防护。
- 若故障恢复后仍无法与可信参考相符，仍应保持停车；不能因“数据重新稳定”就宣称它是正确坐标。
