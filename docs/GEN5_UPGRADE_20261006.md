# Gen5 固件更新（2026-10-06）

本版基于车上当前提交 `7dc6d00`，保留驱动器 10 Hz 控制与 1 秒反馈超时。

- 落实已经确认的“卫星为准”融合规则：双固定解、有效测向和 0.30–0.50 m 基线的新鲜观测优先；删除旧的卫星互检否决、位置矛盾与推算预算停车检查。主天线固定解中断仍最多维持 5 秒，恢复后沿用自动继续逻辑。
- 长直线加入横向趋势反馈，正常速度渐入阻尼和稍强的积分；内层航向 PID 保留。低速沿用原控制。
- 顺时针、半径 1.5–5 m 的完整圆在常规速度下取消额外 50 ms 入圆前瞻，保留原执行延迟补偿及两脉冲整形。逆时针、低速、部分圆弧和范围外半径沿用原处理。

离线对照支持上述限定范围的平均收益，不保证每次及所有子指标改善，也没有实车行驶验收。旧喷头几何补充对照中，个别模型整圈横偏 P95 均值增加约 0.03 mm、尾段峰值均值增加约 0.21 mm。

安装使用签名升级包和既有车辆升级接口；更新时要求底盘在线、停车和任务空闲，不发起作业。不修改平板设置、车辆喷头标定、CORS 账号或 CAN 波特率配置。
