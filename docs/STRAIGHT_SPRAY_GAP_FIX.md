# 直线偏离与停喷缺口修复（2026-10-05）

实车 0c8969cc 在开始约 10.46s 时喷头定位估算横偏超过 3cm，停喷约 2.04s，期间仍下发 0.8m/s；峰值 6.06cm。按原记录的执行进度估算，受影响区间为 2.8273～4.47474m，约 1.65m。这是喷线许可与定位估算记录，不是实际材料覆盖测量。

## 修改

1. 直线控制接管时保留真实指令历史，用既有 0.8s 混合保持输出连续；不再把单拍的旧转向动作和陀螺暂态反解成长期内环积分。外环已学到的稳态横偏补偿仍保留，控制增益和切入几何条件不变。
2. 仅 Gen5 前进、明确标记的正式喷线直线，按当前和执行延迟后预计喷头横偏渐进减速。达到停喷门槛一半开始收紧，达到门槛时最高 0.45m/s，保持正速度纠偏；低于这个速度的巡航不会被抬高。跟随既有加减速限制。接入、倒车、圆弧及旧底盘不应用此项。喷线 3cm 门槛没有放宽。
3. 普通路线记录已观察到的停喷区间并持久化。许可恢复不会把之前的缺口抹掉；正常线尾关喷、转场、原地等待不虚构欠喷。记录以行驶进度估算，不替代实测材料覆盖。补画是独立任务，原趟历史保留停喷事实供核对。
4. 结束提示明确写“行驶结束，有约 … 米停喷区段，请检查并选段补画”。平板 1.11.18 的报告和历史对有停喷记录的任务提示待检查补画；“剩余未完成”入口指向已有的选段补画流程，不把已走过但停喷的区间说成没有剩余。没有自动倒车、掉头或开启补画。
