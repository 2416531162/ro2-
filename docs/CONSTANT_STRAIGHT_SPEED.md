# 直线按设定速度作业（2026-10-05）

按用户要求，Gen5 路线作业的直线部分取消自动软降速。信号降级、卫星/传感器接管、软误差预算以及定位恢复的低速锁定，不再覆盖直线段的设定速度。横偏接近停喷门槛时的0.45m/s限速、通用横偏降速，以及直线起步固定爬行区间同时跳过。

直线仍按原加速度起步。Gen5 直线喷线的停车线尾按 `LINE_END_RUN_OUT.md`：保持设定速度越过图纸线尾后关泵，再按 1.0 m/s² 斜坡缓停；1.0 m/s 的停距允许超过 0.5 m；其他段仍按原制动曲线停车。当前段巡航速度、倒车段原有配置上限、底盘速度上限不改变；转弯前预减速、曲率/圆弧限速、原地转向与换向停稳逻辑不改变。曲线上的降级限速继续生效。

定位被判为不可控制、硬误差预算/维持时限超限、偏离中止、急停及底盘故障仍停车；本次没有放宽这些控制许可。3cm停喷与欠喷记录继续有效，取消降速不保证不会超差停喷。相关状态文字改成“按设定速度直行”，不会仍显示已经降速。

实现：LineMission 给生产差速路线的 SectionTracker 开启 constant_straight_speed，按当前规划片段的曲率判定。直线只绕过软限速并清掉旧速度迟滞，不修改原始定位质量；路径控制仍执行曲率预减速、加速度及段尾停车。纯计算模块默认保留旧策略，保证旧底盘/独立调用兼容。

验证：130 项相关测试、47 子测试通过；其他转向/停喷/圆收尾/仲裁回归见 preservation-tests.txt。36 个带侧置喷头及霍尔速度的闭环仿真全部完成；最坏模型横偏2.879cm，1个工况存在估算超差停喷，未取消喷线保护。这些不是实际漆线精度承诺。本次不驾驶实车。

核查的新作业仍有未解决项：18趟路线中17趟行驶完成，一趟原地补转仍未对准后中止；5趟存在定位暂停或5趟留有停喷记录（集合不完全相同）。最后一趟正式喷头估算峰值0.67cm且无停喷；倒数第二趟峰值3.81cm，另有约5.3秒定位暂停，停喷区段累计约0.92m。该批还记录2次CAN发送失败，其中1次使IMU直行进入FAULT。不能把策略变更视为这些问题都已修好。
