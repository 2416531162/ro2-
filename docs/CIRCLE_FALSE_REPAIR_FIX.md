# 正常画圆收尾误补圈修复（2026-10-05）

## 证据

基于当前板子源码 `56b0d3107a832072fb73eb0f1a3d285a76f9fb5e`，分析圆作业 `613abc77`。

- 原计划路径长 18.43204 m。正式喷线记录 1108 拍，平均喷头偏差 3.77 mm、95% 1.11 cm、最大 2.13 cm。
- 原圈正式喷线没有任何禁喷帧。
- 控制时刻 `1592.1342`，路径突然延长到 33.03537 m，追加了一整圈。那一拍喷头偏差仅 5.15 mm，速度指令为 0。
- 此后 `1592.7942` 才出现一拍 3.00235 cm 的超差，即追加后 0.66 秒。该事件不能作为此前追加圈的原因。

## 原因

`PathTracker` 在到终点时先进入 DONE。`RouteOperations.capture` 在任务正式结束前记账，
将本拍的喷线阶段传为 false，喷线资格也为 false。
旧 `circle_spray_repair.step` 用「本拍或上一拍在喷线阶段」判断仍需记账；
只要当前 false 且进度有增长，就将正常收尾的最后一段当成欠喷，置 `missing_seen=true`。
随后 capture 看到缺口就立即延长原路径并重启末段，产生了不必要的追加圈。

另外，正常盖头时跳过已覆盖区段也不应创建新的欠喷。
任务 finish 会把逻辑进度设到计划终点，不能将该进度变化冒充一次实际喷线观测。

## 修改

- 只有当前属于应喷线区间时，禁喷导致的经过区间才可形成欠喷。
- 正常离开喷线阶段时，按上一拍有效喷线状态结清已经过的区间，不把正常结束置为缺料。
- 已覆盖位置的主动跳过不进入欠喷阶段记账。
- 欠喷窗口的期望覆盖只计算到已观察的进度，finish 的逻辑完成值不能制造未观察到的尾部缺口。
- 真正禁喷的欠喷账、3 cm 停喷保护与最多追加一圈的约束保留。

这不是将阈值放宽，也没有把超差样本隐藏。原任务期间触发的真实禁喷仍保留补喷依据。
该账本仍是基于定位和喷线资格的估算，不代表地面材料的实测覆盖。
