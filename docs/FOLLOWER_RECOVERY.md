# 电子跟屁虫：局部调姿与限量脱困

本次只完成本地代码和合成场景验证，尚未部署或通过实车验收。后方历史路径并非实时感知，
首次运行前请按文末顺序检查制动、换向和盲区；后续进入盲区的人或物体仍依赖后向传感器。

## 本次行为变化

- 默认开启。正常跟随同时比较左右候选弧线，窄门前可选与目标方向相反的转角，避免只向人硬拐。
- 前方受阻或发出前进指令却持续不动约 1 秒后，进入停稳、短退、再前进的有限脱困流程。
- 底盘驱动不再因短暂的指令速度/里程计速度差永久锁停；跟随层继续根据实测车速做有界脱困。
  这不改变物理急停、雷达防撞、串口/反馈断流停车及传感器故障锁定。若车轮确实顶住障碍或打滑，
  仅凭前方画面通畅不能证明可安全继续加力，应现场检查并验证实车制动与电机温升。
- 人离开视野后，已确认的雷达目标在 0.15 秒内进入接力；雷达必须通过连续轨迹关联门，不再从 4 m 范围内强行选取车后点簇重定位；连续关联得到的车后/侧后目标进入掉头规划（`turnaround.py`）：每周期搜索最多三段满舵前进/反打舵倒车，选相机重新看到人用时最短、且与障碍物和人都保持余量的方案；需要换向时仍先等实测停稳。
- 当前相机没有云台控制，“观察”指停车收集检测结果，扫视由后续车身转动实现，不是假装原地转圈。
- 后侧被车体遮挡时保留最近 4 秒真实扫描的空闲区域，并按实测里程计转换；不是把遮挡区直接标为空地。
  必要时先沿可见的前方通道短距离前进以获得新视角，再转弯。当前可见障碍优先于旧的空闲记录。
- 重新看到目标并具备可行前进路径后恢复跟随；目标进入停车间距或停在距离死区内时停止脱困。

## 默认限制

| 项目 | 默认值 |
|---|---:|
| 观测充分时普通脱困速度 | 0.12 m/s |
| 车后/侧后目标掉头（前进或倒车） | 最多 1.0 m/s（满舵侧向加速度约 0.58 m/s²），每段按剩余行程与扫掠净空收油 |
| 车后雷达目标反打舵倒车 | 最多 0.20 m/s |
| 观测充分时单段后退 | 最多 0.35 m |
| 单段前进搜索 | 最多 0.70 m |
| 后方盲区短退 | 每轮累计最多 0.30 m、0.08 m/s |
| 可追溯的前进车身路径 | 最近 20 秒且最近 1.5 m；扫描记忆另限 4 秒 |
| 换向前持续静止 | 0.30 秒，实测速率小于 0.02 m/s |
| 脱困总预算 | 75 秒 / 12 段 / 6.5 m / 累计转角约 186°，任一先到即停止 |
| 重置耗尽预算 | 正常跟随前进至少 0.30 m；耗尽后 20 秒可重试搜索，但不补充盲退里程 |

155°–230° 的雷达遮挡在配置里写为跨 ±180° 的 `(155, -130)`。
空扫描、NaN、未采样角度、近于量程下限及车体自反射均不作为空地证据。
N10P 明确标记已采样的前半球 `+inf` 表示无有效回波：按量程上限的远距离假设
参与路径净空计算，依赖该假设时跟随与驱动均限制到 0.12 m/s；不等于证明
沿途绝无透明、低矮或吸收激光的障碍物。旧扫描发布者没有采样标记时仍按未知处理。
至少需要 10 个车体外的有限回波才接受含该假设的扫描；真实障碍物优先、
过期扫描仍停车。
盲区后退只允许整个扫掠车身位于最近前进经过的车身走廊内；没有历史路径、历史过期、
转弯需要扫过未观测区域或当前扫描出现障碍时停止。盲区预算不会因反复尝试刷新。
距离采用底盘反馈积分，并在距离上限前应用制动包络，不以运行秒数代替行程。

这是局部路径尝试，不是保证走出任意死胡同的全局导航。
历史通行记录不等于后方实时可见：后来走进盲区的人或物体仍需后向传感器才能发现。
平面雷达也不覆盖台阶落差及扫描平面以外的障碍；首次验证需在受控平地逐项检查。

## 运行与观察

设备端保持原有相机、雷达和底盘服务；不要同时运行两个跟随节点。
先使用不发布轮子指令的模式观察新状态：

```bash
python3 radar_system/person_follower.py --dry-run
```

默认运行自动启用脱困。临时恢复“丢人停车、不自动倒车搜索”行为：

```bash
python3 radar_system/person_follower.py --no-recovery
```

`--no-recovery` 不取消碰撞检查、数据时效检查和左右局部选路。
`/follower/status` 新增 `recovery_enabled`、`recovery_phase`、`recovery_legs`、
`recovery_distance_m`、`blind_reverse_used`、`recovery_exhausted`。
新状态包含 `ALIGNING`、`SEARCH_SCAN`、`SEARCH_TURN`、`RECOVERY_REVERSE`、
`RECOVERY_BRAKE`、`RECOVERY_WAIT`、`RECOVERY_EXHAUSTED`。

底盘状态必须含 `connected`、`armed`、`holding`、`age_ms` 和
`telemetry.velocity=[vx, vy, wz]`；本仓库驱动已经发布这些字段。
雷达超过 0.5 秒或反馈超过 0.3 秒未更新、传感器冲突、低电压、驱动暂停/解除使能均停止。
停止指令直接清零，不让速度斜坡残留越过新限幅。

## 验证

```bash
python3 tests/test_follower_recovery.py
python3 tests/test_motion_safety.py
python3 tests/test_footprint.py
python3 tests/test_perception.py
```

这些是合成激光、模拟底盘反馈和 ROS 消息替身测试，不是实车或 ROS 集成验收。
过门测试包括：80 cm 门口不同接近位置，以及 85 cm 门口从横向偏移 4 cm、偏航 5° 起步，
分别检查后方可见与 155°–230° 遮挡的情况；每步检测实际车身四边是否碰到门框。
实车验收顺序：空旷场地丢人搜索 → 目标重新出现停止搜索 → 有后向观测的短退 →
最近走过直线路径的盲区限量短退 → 窄门对正 → 前后均堵停止 → 中途切断雷达/反馈停止。
逐项测量实车行程、转向符号、换向停稳和轮胎打滑；后向实时传感器完善前不扩大盲退额度。

改动与恢复记录位于 `artifacts/follower_recovery/VERIFICATION.txt`。
恢复脚本接受目标仓库目录并校验文件哈希；发现后续修改时退出，不覆盖后续工作。


## 观测不足与真实障碍分离（2026-09-18）

`OBSERVATION_WAIT / insufficient_observation` 表示路径因缺少有效回波而无法确认，
不代表发现障碍。所有前向候选均因未知区域失败时保持停车等待，不启动新的脱困回合、
不消耗换向次数。真实回波挡住路径仍走原障碍停车/有限脱困流程。
AEB 因未知区域限速到零时也明确显示观测不足；所有碰撞和未知区停车限幅保留。
原始回波、邻居插值窗口和扫描屏蔽范围没有放宽。

现场 199 帧中右前约 -30° 至 -22° 持续无有效回波，两侧有回波，
不能视为偶发分桶漏点。将真实扫描与合成静止目标/反馈组合回放：199 次均等待观测、
脱困段数为 0；这不是实际运动验证。须检查该方向结构遮挡、安装和反射条件。
全套测试：433 passed、8 skipped、6 subtests passed。

## 视线障碍绕行（2026-09-21，本地验证）

相机深度测得的人与车之间出现较近雷达回波时，只有同时满足以下条件，才不把
该回波作为人的跟随距离，而交给车体扫掠选路处理：最近 0.50 秒内雷达已关联
到目标；当前有效扫描在本次相机检测位置 0.30 m 内仍有腿部点簇；较近回波
比人的车头间距短至少 0.35 m。当前扫描看不到腿、相机检测未能对应锁定目标
或雷达失效时，继续按较近距离保守限速/停车。障碍仍进入扫掠检查、刹车包络
和 AEB。状态遥测的 `target.los_obstacle_gap` 显示判为视线障碍的车头间距。

纯追踪与 MPPI 的参考量仍经过同一局部扫掠选路。候选弧线增加较小转角，
净空打分按车头到人前停车点的剩余距离评估（0.65–1.40 m），绕障方向
有 0.10 的短时滞回；仅停在 `HOLDING` 时允许预打舵，不覆盖绕障
`ALIGNING` 转向。堵转判定读取上一周期最终下发的速度，避免控制层
实际已停车却进入倒车脱困。

验证：新增的 12 项视线障碍、闭环绕柱、空地跟随、MPPI 下游选路与几何选路单测通过；
MPPI 运行相关测试 50 通过、3 跳过。闭环场景使用全可观测的合成雷达，
**未覆盖板端默认结构遮挡扇区**。完整测试在改动前后均有相同的 47 项失败、
11 项跳过；这些失败包含默认遮挡下的跟随与底盘防护测试，不能把局部回归
通过当作整车验收。Jetson 已通过 SSH 只读检查，现有运行服务及发布目录
未切换；实际扫描覆盖、制动/延迟/满舵标定和 MPPI 负载仍须在受控场地复测。

## N10P 无回波远距策略（2026-09-21）

上文 2026-09-18 的“无回波等待观测”记录描述旧运行策略。现在仅在 N10P
的 `intensities` 明确区分已采样角度时，将前半球已采样的 `+inf` 作为截至
`range_max` 的远距离假设，包括旧标注为右前结构遮挡的方位；车后会被
车体本身遮挡，仍按未知处理。未采样格、`-inf`、NaN、车体自反射及过期
扫描不适用。至少保留 10 个外部有限回波；实际有限障碍仍优先于远距假设。
跟随路径和驱动防撞层任一处依赖该假设均限制为 0.12 m/s，状态里分别显示
`no_echo_path_used` 和 `guard.no_echo_used`。这是放宽通行策略，不是扫描
平面外障碍已消失的证明；运行版仍需现场验证制动和物理覆盖。
