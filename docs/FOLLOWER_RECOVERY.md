# 电子跟屁虫：局部调姿与限量脱困

本次只完成本地代码和合成场景验证，尚未部署或通过实车验收。后方历史路径并非实时感知，
首次运行前请按文末顺序检查制动、换向和盲区；后续进入盲区的人或物体仍依赖后向传感器。

## 本次行为变化

- 默认开启。正常跟随同时比较左右候选弧线，窄门前可选与目标方向相反的转角，避免只向人硬拐。
- 前方受阻或发出前进指令却持续不动约 1 秒后，进入停稳、短退、再前进的有限脱困流程。
- 人离开视野后先停车观察 0.8 秒，再向最后目标方向（或更畅通的一侧）走弧线搜索；需要时停稳后换向掉头。
- 当前相机没有云台控制，“观察”指停车收集检测结果，扫视由后续车身转动实现，不是假装原地转圈。
- 后侧被车体遮挡时保留最近 4 秒真实扫描的空闲区域，并按实测里程计转换；不是把遮挡区直接标为空地。
  必要时先沿可见的前方通道短距离前进以获得新视角，再转弯。当前可见障碍优先于旧的空闲记录。
- 重新看到目标并具备可行前进路径后恢复跟随；目标进入停车间距或停在距离死区内时停止脱困。

## 默认限制

| 项目 | 默认值 |
|---|---:|
| 观测充分时脱困速度 | 0.12 m/s |
| 观测充分时单段后退 | 最多 0.35 m |
| 单段前进搜索 | 最多 0.70 m |
| 后方盲区短退 | 每轮累计最多 0.30 m、0.08 m/s |
| 可追溯的前进车身路径 | 最近 20 秒且最近 1.5 m；扫描记忆另限 4 秒 |
| 换向前持续静止 | 0.30 秒，实测速率小于 0.02 m/s |
| 脱困总预算 | 75 秒 / 12 段 / 6.5 m / 累计转角约 186°，任一先到即停止 |
| 重置耗尽预算 | 正常跟随前进至少 0.30 m；耗尽后 20 秒可重试搜索，但不补充盲退里程 |

155°–230° 的雷达遮挡在配置里写为跨 ±180° 的 `(155, -130)`。
空扫描、NaN、inf、缺失方位、车体自反射均不作为空地证据。
盲区后退只允许整个扫掠车身位于最近前进经过的车身走廊内；没有历史路径、历史过期、
转弯需要扫过未观测区域或当前扫描出现障碍时停止。盲区预算不会因反复尝试刷新。
距离采用底盘反馈积分，并在距离上限前应用制动包络，不以运行秒数代替行程。

这是局部路径尝试，不是保证走出任意死胡同的全局导航。
历史通行记录不等于后方实时可见：后来走进盲区的人或物体仍需后向传感器才能发现。
平面雷达也不覆盖台阶落差及扫描平面以外的障碍；首次验证需在受控平地逐项检查。

## 运行与观察

设备端保持原有相机、雷达和底盘服务；不要同时运行两个跟随节点。
先使用不发布轮子指令的模式观察新状态：

```bash
python3 radar_system/person_follower.py --dry-run
```

默认运行自动启用脱困。临时恢复“丢人停车、不自动倒车搜索”行为：

```bash
python3 radar_system/person_follower.py --no-recovery
```

`--no-recovery` 不取消碰撞检查、数据时效检查和左右局部选路。
`/follower/status` 新增 `recovery_enabled`、`recovery_phase`、`recovery_legs`、
`recovery_distance_m`、`blind_reverse_used`、`recovery_exhausted`。
新状态包含 `ALIGNING`、`SEARCH_SCAN`、`SEARCH_TURN`、`RECOVERY_REVERSE`、
`RECOVERY_BRAKE`、`RECOVERY_WAIT`、`RECOVERY_EXHAUSTED`。

底盘状态必须含 `connected`、`armed`、`holding`、`age_ms` 和
`telemetry.velocity=[vx, vy, wz]`；本仓库驱动已经发布这些字段。
雷达超过 0.5 秒或反馈超过 0.3 秒未更新、传感器冲突、低电压、驱动暂停/解除使能均停止。
停止指令直接清零，不让速度斜坡残留越过新限幅。

## 验证

```bash
python3 tests/test_follower_recovery.py
python3 tests/test_motion_safety.py
python3 tests/test_footprint.py
python3 tests/test_perception.py
```

这些是合成激光、模拟底盘反馈和 ROS 消息替身测试，不是实车或 ROS 集成验收。
过门测试包括：80 cm 门口不同接近位置，以及 85 cm 门口从横向偏移 4 cm、偏航 5° 起步，
分别检查后方可见与 155°–230° 遮挡的情况；每步检测实际车身四边是否碰到门框。
实车验收顺序：空旷场地丢人搜索 → 目标重新出现停止搜索 → 有后向观测的短退 →
最近走过直线路径的盲区限量短退 → 窄门对正 → 前后均堵停止 → 中途切断雷达/反馈停止。
逐项测量实车行程、转向符号、换向停稳和轮胎打滑；后向实时传感器完善前不扩大盲退额度。

改动与恢复记录位于 `artifacts/follower_recovery/VERIFICATION.txt`。
恢复脚本接受目标仓库目录并校验文件哈希；发现后续修改时退出，不覆盖后续工作。
