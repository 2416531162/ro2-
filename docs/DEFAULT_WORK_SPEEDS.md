# 默认划线 0.8、转场 1.5 m/s（2026-10-04）

新建或未指定速度的场地任务默认划线 0.8 m/s、前进转场 1.5 m/s。普通路线未给 cruise 时默认 0.8 m/s。App、场地编辑器、车端规划入口和离线仿真器同步；已保存或导入图纸的显式速度保留，不擅自改写历史任务。

不修改底盘驱动上限（Gen5 原本已是 1.5 m/s）、急停、定位保护、倒车或曲率限速。1.5 m/s 是前进赶路巡航目标，短距离和弯道不保证达到；速度变化仍受加速、制动、起步慢走限制。

弧线转场末段与划线合并时，增加内部 `entry_speed`，划线起点沿用 `paint_from`。跟踪器在包含执行延迟和前视的预测位置上计算减速距离，进线前降至该划线段的速度。圆形划线速度继续按喷头半径转换为后轴速度。合并路径保持不停车进线。

任务存档、恢复、截取剩余路径保留 entry_speed/paint_from；断点已进入划线区时不重新套用高速转场。补画和续行的独立接入段也允许前进 1.5 m/s。

输入和执行上限同步为：划线参数保持原范围，前进转场及内部后轴分段速度不超过 1.5 m/s。新增模块 `radar_system/motion_speeds.py` 集中车端默认值。

## 除急停外都渐停（2026-10-04 补）

用户：「暂停作业也要缓和刹住，只有急停采用急刹」。

原来：操作员暂停 / 停止 / 结束作业、跟踪中止（偏离等）、存档失败暂停时任务层一拍给零；任务一结束节点下一拍就发 0 并交还控制权。OID 节点收到 0 立即清零，驱动器按 3 m/s²（`wheel_decel_mps2`）刹停。降级 / 推算预算限速变低时跟踪器也是一拍截到上限。另外原有的定位暂停渐停按 1.5 m/s² 降，但 OID 节点对非零导航指令按车型 `driver.acceleration_m_s2`（Gen5 1.0 m/s²）双向限斜率，只跟得上 1.0，任务层降到 0 那一拍还剩 0.3–0.5 m/s 被清零。

现在：
- `LineMission._limit_decel`：任务层发出的车速每拍最多降 `SOFT_STOP_DECEL_MPS2`·dt，转弯曲率不变；原地转中停下角速度按原地转角加速度降。不管停车原因（暂停、停止、结束、中止、存档失败、定位暂停、横偏降速）。蠕行速度 0.07 m/s 以下照旧直接给零（到点停准不受影响）。
- `SOFT_STOP_DECEL_MPS2 = min(1.5, driver.acceleration_m_s2)`：Gen5 1.0 m/s²，与驱动节点斜坡一致；Wheeltec 1.5。
- 降级 / 预算限速按同一减速度逐拍收紧后再交给跟踪器，跟踪器边减速边跟线。
- 任务结束但车还在渐停时（`mission.braking`），节点照常下发、不交还控制权，指令降到 0 才交还；暂停仍是停稳 0.3 s 才转「已暂停」。
- 急停：仲裁直接切 ESTOP，任务层不管，立即零速，驱动器 3 m/s²。手动接管（MANUAL）同样不经过这里。
