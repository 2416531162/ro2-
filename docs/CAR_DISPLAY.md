# 主板外接显示屏

页面 `/display`，入口 `radar_system/car_display_window.py`。2026-09-26 按用户要求改为固定视角、自动跟车，关闭地图拖动及缩放。Android 工程不参与此功能。

有车辆位姿时，镜头按用户参考照片沿车身中线从后方跟随车辆位置及车头方向：相对车头偏转 0°、俯角 30°、默认观察距离约 3.2 m（实际车身 0.75 m 对应 3.225 m，按车身尺寸和窄屏适配）；镜头目标放在后轴前方至少 0.95 m，让车辆居中偏下、保留前方视野，位置和转向用时间相关的平滑过渡。没有定位时显示静止车辆示意；有路线但无位姿时展示全路线。车辆不能在这个页面被控制。

WebKitGTK 2.46.5 的实机触控测试发现，原页面收到的是 TouchEvent，原先的 PointerEvent 地图手势没有接管触屏，原生捏合会放大整页。现在以非 passive 的 touchstart / touchmove 拦截原生缩放，同时阻止滚轮、gesture 事件和键盘整页缩放；viewport 和 CSS 限制作为补充。没有地图输入处理器，也没有手动查看倒计时。

动画与屏幕刷新同步，静止时不重复绘制。车辆位置、转向、轮子或显示原点变化时更新阴影；只移动镜头时复用阴影。

验证：

```sh
node --test tests/test_display_interaction.cjs
python3 -m pytest tests/test_car_display.py -q
```

固定镜头、自动跟随、输入拦截、静止省绘制和阴影更新共 6 个 JS 测试通过；显示接口 11 个 Python 测试、7 个子测试通过。主板使用临时 uinput 触摸设备，分别向地图和右侧状态栏注入系统原生双指手势：页面缩放始终为 1，右栏宽度始终为 600 px，示意视角距离始终为 3.225 m，WebGL 无错误。位姿跟随使用测试数据验证，未让实体车辆运动。
