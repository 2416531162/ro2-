# 实车喷线估算（App 1.11.8）

当前启用的是 `/app/spray-trace`：App 将实车喷头位置、速度、作业状态及图纸发送给独立服务，随实际行驶计算预计喷量，不运行一辆虚拟车，不调用任何车辆/HC-08 控制接口。只在实车作业及接近线头的助跑时计算开阀，转场、暂停、换向、定位失效或超过 0.6 秒观测断档会断开喷线。当前还未自动驱动真实水泵，手动水泵开关仍需操作员明确点击。

地图显示实车喷头处的预计落料轨迹；橙色“少喷（预计）”、红色“过量（预计）”仅代表压力、阀延迟与喷宽模型下的估算，不是测量到的实际出料。还没走到的图纸不会被标成少喷；完成后才计整条图纸。停车尾喷、重复走线和越线料量不会被删掉。当前默认开阀 150 ms、关阀 100 ms、喷量响应 50 ms、命令周期 200 ms、线宽/喷宽各 5 cm、±15% 剂量容差；真实泵流量曲线和阀延迟需后续测量。圈线按当前段剩余路程关阀，折线按原图几何分箱，统计独立于显示点裁剪。

底栏水泵为场地、作业、手动、水泵、更多中的独立操作入口，点开压力/开关面板，不切换页面、不自动开泵；关/开/等待状态以车辆确认数据更新。正常驾驶、作业、推行和急停入口保留。

独立 systemd 服务以 `--observe-only` 运行，不接管车辆服务。PrivateDevices、DevicePolicy、地址族、权限、CPU、内存限制保留。运行包从当前车辆来源提交为基底加功能，再从 Git 提交 stage/verify；安装只启动喷线服务，车辆主发布版不切换。安装前再次核对 current 发布 ID。

软件验证：`tests/test_spray_live_trace.py` 覆盖折线投影、实车坐标、尾喷、断档、暂停转场、去重及无效位置；旧数值测试保留。App 底栏触摸和驾驶解锁用本机假车辆验证，不让实车转轮或开泵。

以下是保留的离线数值工具说明；当前 App 不自动调用，观测服务模式不开放该端点。

# 模拟喷水

App 1.11.6 连接车辆后，自动把当前图纸、选中的边、喷头偏置、速度和压力参数发到板子 19088 端口的 `/app/spray-simulation`。改变这些参数会重新模拟，无需按开始。没有图纸时提示先选择图纸。完成后可点“重播模拟”，以 4 倍速查看喷线。

地图青色轨迹只记录虚拟喷量大于 0.5% 时的喷头位置，转场和断喷处断开。橙色是模拟少喷，红色是模拟过量；最终给出覆盖率、少喷长度、过量长度和越线料量。越线料量的单位是按正常喷量折算的米，不是几何轨迹长度。是否过量单独统计，覆盖率高也可能过量。统计来自连续落料积分，地图降采样不参与统计。

## 隔离与适配

使用同一发布版中的 FieldPlanService、LineMission、PathTracker、定位融合、Gen5 配置计算虚拟车辆，保留当前板子 `284bbaac` 的入弧前馈整形。底盘模型为轮速延迟/滞后、万向轮和定位噪声；角速度采用当前实测二阶响应（1.1 Hz、阻尼 0.30、延迟 0.05 s、增益 1.05）。旧阿克曼协议不改变。

模拟服务单独运行，不接管运动服务。数值子进程禁止网络、ROS、CAN、蓝牙、串口、外部命令、设备读写和模拟目录外写入；systemd 再限制设备、地址族、权限、CPU 和内存。App 的模拟模式通过统一发送入口拦截车辆、水泵、推行、路线启动等控制指令，保留心跳和操作员明确点击的急停。水泵参数只改变本地模拟参数。

一个板子同一时刻只计算一份图纸，相同参数复用结果；另一份图纸替换旧模拟。最多 3 个随机种子、3600 秒虚拟时间，进程 120 CPU 秒/180 秒墙钟上限。最近 20 份历史保留，至少保留五分钟供正在退出的任务清理；地图回放点和统计分箱有上限。服务重启/图纸被替换后，App 自动重新提交自己当前图纸。

## 模型与限度

默认虚拟线宽/喷宽 5 cm，开阀延迟 150 ms、关阀 100 ms、喷量一阶响应 50 ms、命令周期 200 ms，压力范围 1–100%。基准喷量以设定压力在设定划线速度下为目标；补偿使用估计位置、速度、加速度及规划进度，提前开关、按速度调整压力，并保留虚线间隔。对估计横偏造成的线内喷量损失做最高 1.6 倍补偿（位置余量可设 0–20 mm，默认 0，以免追逐定位噪声而过喷），仍受 100% 压力上限限制；不能消除位置误差和越线料量。真实位置仅用于独立计量，没有给控制器看未来真值。

每 2 cm 分箱累计落料，目标量的 ±15% 范围内算合格，不足/超过分别标出，重复喷涂、停车积料、延迟尾喷和越线喷量均保留。低压/高压上限、急加减速、定位误差、短虚线可能仍产生少喷或过量，界面如实显示，不能用仿真覆盖率承诺实物不漏喷。实际泵的压力—流量曲线、材料粘度、阀延迟仍需测量；此功能不改变真实泵限幅，也不发 HC-08 指令。

## 部署与来源

以车上当前 `manifest.json.source_commit` 为基底；从包含本功能的 Git 提交用 `deployment/manage.py stage --git REV` 打包、比较当前清单、上传并 `verify`。安装只用 `deployment/install_spray_simulation.py RELEASE --expected-current ID` 启动独立 `rk3588-spray-simulation.service`，它引用候选版本中的数值代码；车辆 `/opt/rk3588/current` 和原有服务保持其当前版本。安装前会再次核对当前发布 ID。完整车辆发布可在用户明确部署时走原有 activate 流程。

运行相关测试：`python3 -m pytest -q tests/test_spray_simulation.py`；App 的 SpraySimulationTest 测协议守卫和结果解析，SpraySimulationInstrumentation 用本机 HTTP 假服务验证自动开始、失败重试、断喷轨迹和地图覆盖层，不连接车辆。
