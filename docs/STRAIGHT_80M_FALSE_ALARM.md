# 80 米高速直线误报修复（2026-10-03）

本轮只修改定位一致性检查，未改路线跟踪增益、默认作业速度、3 cm 横向预算或驱动看门狗，未提交、未部署。

## 原因与证据

80 米直线、喷头速度 1.0 m/s、种子 3，在没有注入故障时触发 `gnss_displacement_conflict`，随后预算停车，600 秒内未完成。失败发生在开始划线约 7.3 秒后，实际只画了约 4.5 米，不是因为后半段 80 米路线失控。

测量时刻 101–104 秒的短窗口中：

- 轮程＋融合航向预测的侧向位移与 GNSS 相差约 4.962 cm。
- 当时侧向门限约 4.845 cm，只超过约 1.2 mm。
- 融合航向与底盘真值有约 0.74° 的差异，随行驶距离放大为位移差。
- GNSS 位移与 Doppler 天线地速积分只相差约 1.1 cm，并不支持“卫星位置跳错”。

上一版长窗口要求 Doppler 佐证，但短窗口只要轮程残差过线就直接隔离 GNSS。误隔离后，恢复仍拿带误差的冻结参考比较，导致任务无法恢复。速度从 0.5 增到 1.0 m/s 后，相同 3 秒窗口的路程翻倍，这类推算误差更容易越过门限。

## 修改

- 长短窗有有效地速时均要求同轴、同方向的异常证据；不能把轮程横向差与地速纵向差当成同一个故障。
- 小幅超限需要持续 0.1 秒确认；证据充分且明显越界时快速隔离。地速不能佐证时保留短窗保护，长窗不单靠轮程下结论。
- 地速断过再恢复时，优先使用同一有效积分区间的参考，避免拿不完整积分来决定证据缺失。
- 等待确认的可疑位置不先进入融合，也不作为新的参考点，防止断流后第一帧错误位置被先接受。
- 增加“测向有小偏差但位置和地速一致”“单帧边界跳动”“明显共同跳变”“断流后错误首帧”的回归测试。1 m/s 航向偏差用例在旧版失败，新版通过。

## 必须保留的限制与代价

少误报不等于所有故障精度更好。增加交叉证据会延迟部分慢漂识别：0.5 m/s 直线中注入 2 cm/s 共同慢漂，3 个种子的最大喷头真值横偏从上一版约 1.87–3.02 cm，变为约 3.95–4.26 cm；停车指令相对上一版晚约 0.36–1.10 秒。故障消除后均恢复完成。

0.5 cm/s 慢漂仍有约 9–10 cm 偏差后才停车的情况，附加地速噪声的用例峰值约 11.5 cm。更慢漂移不能保证识别。这次修复解决的是正常高速直线误隔离，不是所有环境下 3 cm 内发现并停车的保证。

模型和种子测试不能代替实车喷头真值验证。不能把 10/10 当作实车成功率，也不能用当前估计预算声称地面真实误差永远小于 3 cm。
