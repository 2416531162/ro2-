# 真实驱动水泵开关

App「更多 → 真实驱动水泵」：关闭就是模拟，开启后授权车端在合格的作业喷线阶段实际驱动水泵。
开启模式本身不立即开泵；启用前必须停车、没有运行或保留任务，并且输出后端已就绪。
真实驱动开启后，非作业期间可手动开关水泵和调整压力；推行模式也允许这些操作，切换推行不会关泵。
开始自动作业时结束手动输出，再由喷线资格控制；作业期间手动关闭会同时取消自动真实驱动，避免立即重开。
模拟模式仍不实际出料，手动面板会提示先开启真实驱动。
关闭模式可在作业中进行，会关泵并禁止任何连接重新手动开启。

`pump` 新增 `action: mode`，使用既有 `enabled` 布尔值、`pressure` 整数及 `run`。
`enabled: false` 对应 `simulation`，`true` 对应 `real`。
遥测增加 `output_mode_supported: true` 和 `output_mode`（`manual/simulation/real`）。
旧 App 的默认手动控制保持兼容；新 App 连接后将旧手动模式明确切到模拟，真实模式以车辆确认状态显示。

真实模式的作业自动输出由车辆 50 Hz trace 的喷线资格控制，还须有新鲜、运行中的路线状态和底盘许可。
暂停、转场、定位异常、偏线、静止、资格断档及结束均关泵；既有急停和故障保护继续生效。
断开平板不会取消已明确授权的自主作业开关，续租由车端负责。模式不写入持久配置，服务重启不自动授权开泵。
手动关闭自动输出时取消真实模式，避免下一帧又开泵；非作业期间手动关闭保留真实模式，允许再次手动开启。

真实出漆维持设定压力，不随虚拟喷量频繁修改 HC-08 压力参数。压力只在用户设置时改变，作业中不允许修改。
模拟喷量通过既有隔离观测服务计算，不向真实输出发送模拟压力或虚拟阀命令。

只使用假输出完成模式、喷线边界、断档、手动关闭及急停测试，不进行实物开泵、喷漆或转轮测试。
真实阀延迟和落漆精度需另行实测，软件模式测试不能确认喷漆边界精度。
