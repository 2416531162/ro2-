# 转向响应自适应验证

代码功能检查通过；**地面漆线精度未验收，未装板**。补偿只在数据支持时生效，不能把“加入自适应”当作已经解决草地 S 型。

| 检查 | 结果 |
|---|---|
| 原有 156 组，最大横偏 ≤15 mm | 开启前后均为 149/156；最坏 15.436 mm |
| 新增 18 组途中响应变化 | 8 组最大偏差下降，10 组不变 |
| 全部 174 组最大误差 | 18.448 mm；161/174 达到 15 mm |
| 换地面后的均方根误差 | 3 组改善，6 组升高，9 组不变；最坏增加 0.127 mm |
| 补偿系数 | 全部保持在 0.85～1.15 |
| 历史 27 份作业 | 17 个低速段回放，12 个段不在低速范围；0 个窗口获学习确认 |

旧记录中的转向变化、连续可用时长或模型解释程度不足时，自适应保持默认；这个结果只能证明它没有强行从旧数据套用倍率，不能证明新算法在真实草地一定更好。

`validation.json` 保留每组开关自适应的完整指标，`recording-replay.json` 保留所有作业的学习门状态。原始日志留在本地。`full-tests.log` 和 `targeted-tests.log` 为软件测试；旧 RunupStart 对照断言在原基线也失败，没有删除。

运行方式见 [功能说明](../../BOUNDED_STEERING_RESPONSE.md)。
