# 起步限速锁死与接入反复停车（2026-10-05）

本次核查时，车上最新作业仍为 2cfc4095，没有 b2422a73d48ca71c 更新后的新作业。末次 seg01 原地转向后等待约 4.9s，再倒车后又等待约 4.6s，最后 CAN 故障结束；seg02 仅移动约 15.5cm 后等满 5s 停稳超时。上一版已经修复这些 CAN 瞬态拥堵和停稳证据冲突。

另发现 c0680e99/seg02 在定位仍可用于控制、预算允许行驶时，连续约 8.4s 下发零速；seg03 存在长期约 0.133m/s 的低速。DegradedSpeedLimiter 在降级起步时把上限设为 min(许可, 上一拍速度)，且降级期间永远只能收紧。短暂降级可以把它锁到零或很低的速度，卫星航向提示未完全消失就不能释放。

## 实际修改

- 短时预算抖动仍立即收紧限速。连续一秒每拍都有明确的正向速度许可，才按 0.2m/s² 缓慢恢复到窗口中最保守的许可上限；更严许可、零速或控制观察缺口立即中断恢复。完全恢复定位后仍走原有恢复流程。没有取消不可用定位、真正中断超时或故障停车。
- 明确标记的接入、转场及喷线前助跑，不以喷线 3cm 横向精度预算直接触发停车；改用 10cm 横向、20cm 沿线导航预算重新计算完整制动余量，允许时最高按配置的卫星接管速度（车上 0.45m/s）持续调整。真正超过导航预算、数据缺失和中断超时仍停止。
- 正式喷线预算不放宽。接入到喷线边界若当前帧还带接入降级标记，也拒绝出料，避免提前一拍打开水泵。
- 新增分段直线内环诊断到实时状态及控制追踪，保留目标航向、积分、旧控制与内环输出、混合比例，便于实测核对切换过程。

## 验证与限度

253 项测试、111 个子测试通过，另有一个既有测试在未修改的 e23b30d 基线中同样失败：它断言差速默认关闭直线内环，但生产配置此前就已启用。此项单独记录，不计为通过。控制追踪 doctest 与 diff 检查通过。

对同一录包观测序列单独回放限速器（不改变原车辆轨迹）：c0680e99/seg02 的零速限速由 696 拍降到 272 拍，约 13.9s -> 5.4s；它不代表新版本闭环实车已经完成任务。seg03 中预算/可用性反复中断的部分不能靠限速恢复逻辑单独解决，所以同时修复了非喷线阶段的预算用途。

最差直线 0c8969cc 的正式喷头估算横偏峰值 6.06cm、超过3cm约2.02s。原始记录与近似影子重算支持检查起步摆动期间控制切换带入的内环暂态；重算后半段不能严格还原在线输出，不能据此宣称唯一根因已确定。

试验了“稳定0.3s后才接入直线内环”的候选，只在本机验证。48 对同随机输入、两种底盘动态、两种速度、三种延迟、8/20m直线中，两版均完成；整体横偏P95中位 1.418 -> 1.427cm，5/48 对变差超过1mm，最大退化0.562cm。因此不采用这项候选，保留原转向控制算法、增益、喷头尺寸。它不能被算成已解决直线精度。
