# 作业中平滑切换巡航速度

入口：App「作业 → 进行中的作业 → 巡航速度」。点选 0.3、0.5、0.8、1.0 m/s 即发送请求，等待车端确认目标后显示选中档位。不需要暂停、停止、重建路线或重新开始。

本次只调整划线/路线巡航目标。场地转场的 1.5 m/s 目标和接入速度保持不变；弯道、倒车和定位异常仍取更低的限速。普通路线的接入段也与后续路线分开标记，在线调整不会修改它的目标。

## 控制与持久化

- `live_cruise.py` 校验任务身份、运行状态、参数范围和定位后，先保存目标再应用到当前控制器，保存失败不部分执行。
- `PathTracker.set_cruise` 只更新目标，按现有加/减速度逐周期调整巡航参数；不清空积分、历史指令、路线位置或当前段。
- 本次 Gen5 默认 50 Hz、加减速度 0.5 m/s²，巡航目标每周期最多变化约 0.01 m/s；安全停车与曲率限速仍具有优先权。这不表示人完全感觉不到速度变化，也不保证所有安全制动都受这条变化率限制。
- 对场地的圆和圆弧，根据喷头偏移及曲率换算后轴目标，再按转向角速度、弯道加速度封顶，与开始作业的规划（`field_planner.speed_for`）同一公式；保留几何路径和原来的 `entry_speed`。
  2026-10-04 补：原先只换算不封顶，角球弧在 0.8 m/s 时规划为 0.52，在线调速会写成 1.16（1.0 档写成 1.45）。跟踪器运行时本来就按弯道加速度限速，实际车速不受影响，但任务记录和上报的分段目标是错的，转向角速度封顶也丢了。`test_live_speed_matches_a_fresh_field_plan_at_the_same_speed` 用整场足球场（原地转 / 圆弧）核对：在线调到同一速度，24 段刷线速度与重新规划完全一致。
- 只修改当前任务保存的速度。暂停/重启后的目标保留，补画结束回到父任务时恢复父任务目标；图纸的下次作业默认值不变。
- App 显示的是车辆确认的巡航目标，实际速度仍看状态条。断线、任务变化和旧车端禁止发送；等待超时不自动重发。窗口重建保留待确认请求与原超时时限。
